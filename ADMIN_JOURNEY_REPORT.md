# Admin Journey Report

This report outlines the user journey for portal administrators.

## 1. Administrative Control Path

1. **Admin Dashboard:** View urgent flags, active workloads, and SLA status.
2. **Operations Workspace:**
   - Manage citizen accounts.
   - Monitor case files.
   - Review AI suggested Legal Guide matches.
   - Assign helpers and record override logs for sensitive cases.
   - Monitor chat channels.
3. **Audit Ledger:** Chronological timelines tracking status updates.
4. **Data Reports:** Simulates data exports.
