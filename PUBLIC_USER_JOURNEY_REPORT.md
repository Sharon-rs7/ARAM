# Public User Journey Report

This report outlines the step-by-step user journey for the citizen/public user.

## 1. User Path Steps

1. **Dashboard Home:** Large action cards (Speak, Type, Track, Chat) guide initial navigation.
2. **Submit Complaint:** A 6-step submission wizard guides users through language selection, issue description, location details, privacy toggles, evidence uploads, and a final summary.
3. **AI Diagnostic Triage:** Displays auto-detected categories, priority ratings, and required checklists.
4. **Case Tracking:** The order-like timeline shows real-time progress.
5. **Secure Case Room Chat:** Enables messaging and document uploads once assigned to a Legal Guide.

---

## 2. Privacy & Trust Signals

- **Identity Visibility Shield:** Options to mask PII (Visible / Partial / Hidden).
- **Preferred Contact:** Restricts notifications to safe hours.
- **In-App Messaging:** Protects phone/email contact details.
