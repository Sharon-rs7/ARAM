# Legal Guide Journey Report

This report outlines the user journey for assigned case handlers (Legal Guides).

## 1. Guide Path Steps

1. **Helper Dashboard:** View workload capacity metrics and assigned active cases.
2. **Case List View:** Displays assigned folders and priority indicators.
3. **Case Management Console:**
   - Review AI triage suggestions.
   - Access evidence files.
   - Record progress notes.
   - Transition case status.
   - Request missing documents.
4. **Secure Consultations:** Private chat interface to communicate with assigned citizens.

---

## 2. Safety Rules

- **PII Masking:** Hides citizen details for hidden visibility cases (shown as *Protected Identity*).
- **Women Support Certification:** Restricts assignments on sensitive cases.
- **Auto-Read Warnings:** Warns before reading sensitive content aloud.
