# User Friendliness Audit Report

This report evaluates how easily a non-technical user, a Legal Guide, and an Admin can interact with ARAM.

## 1. User Cohort Evaluations

### A. Public User (Low Technical Knowledge / Mobile First)
- **First Step Clarity:** High. Landing page features prominent buttons: "Submit Complaint" and "Track Status".
- **Form Length:** Moderate. 8 inputs. However, optional voice narration mitigates input fatigue.
- **Accessibility:** Simple terminology is used. Audio controls allow reading the description aloud.

### B. Legal Guide (Case Handler)
- **Dashboard Usability:** Highly intuitive. Provides clear metrics for workload thresholds and active files.
- **Case Review Triage:** Direct access to requested documents and case note filters makes problem-solving straightforward.

### C. Portal Administrator (Operations Manage)
- **Assignments:** Side-by-side comparison of AI matches, workloads, and language training statistics.
- **Audit Logs:** Chronological trace records listing performed actions.

## 3. Potential User Confusions & Improvements
- **Confusion:** Low-literacy users may not understand the difference between visibility options (Visible, Partial, Hidden).
- **Improvement:** Add inline tooltips explaining: *"Hidden visibility hides your name and phone number from the Legal Guide helping you."*
