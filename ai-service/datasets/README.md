# ARAM V2 — Local Datasets Inventory

> [!WARNING]
> **NON-PRODUCTION / DEMO ONLY**: All local datasets listed below are synthetically generated or templated for local integration testing. They **must not** be used for training production machine learning models, nor should they be used as proof of real-world accuracy.

## Dataset List
1. `legal_complaints_multilingual.csv`: Synthetic complaint texts with symmetric distribution (exactly 30 rows per category across English, Tamil, and Tanglish).
2. `priority_training.csv`: Synthetic priority label data.
3. `authority_training.csv`: Synthetic authority routing recommendations.
4. `language_detection_training.csv`: Synthetic text samples for rule validation.
5. `clean_public_complaints.csv`: Minor placeholder samples.
