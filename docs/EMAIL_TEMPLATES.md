**Accessible Rights & Assistance Management**

## 1. Template Inventory & Schema

All emails are generated by `com.aram.legalaid.service.EmailTemplateService` using responsive HTML and cross-client compatible table structures.

```
┌───────────────────────────────────────────────────────────┐
│ [ HEADER ]                                                │
│ ARAM Legal Assistance Platform (#0F172A Dark Header)     │
├───────────────────────────────────────────────────────────┤
│ [ BODY ]                                                  │
│ Hello {userName},                                         │
│ {message}                                                 │
│                                                           │
│ ┌───────────────────────────┐                             │
│ │   {actionOrOtp}           │                             │
│ └───────────────────────────┘                             │
│                                                           │
│ {importantInfo}                                           │
├───────────────────────────────────────────────────────────┤
│ [ FOOTER ]                                                │
│ ARAM Support: ouraramsupport@gmail.com                   │

```

## 2. Template Specifications

| Template Enum | Subject Line | Key Variables | Usage Scenario |
| :--- | :--- | :--- | :--- |
| `EMAIL_VERIFICATION_OTP` | *ARAM — Your Email Verification Code* | `userName`, `actionOrOtp` (6-digit OTP) | Citizen / Volunteer signup verification |
| `ACCOUNT_VERIFIED` | *Welcome to ARAM — Your Account Has Been Verified* | `userName`, `message` | Successful email verification confirmation |
| `PASSWORD_RESET_OTP` | *ARAM — Password Reset Verification Code* | `userName`, `actionOrOtp` (6-digit OTP) | Forgot password flow (5-min expiry) |
| `SECURITY_ALERT` | *ARAM Security Alert* / Contact Support | `userName`, `message`, `importantInfo` | Password change notices, contact form, blockchain audit |
| `GUIDE_INVITATION` | *ARAM Legal Assistance — Legal Guide Invitation* | `userName`, `district`, `actionOrOtp` (invite link) | Admin-issued volunteer/guide onboarding link |
| `ADMIN_INVITATION` | *Welcome to ARAM — Activate Your Regional Admin Account* | `userName`, `district`, `actionOrOtp` (invite link) | Super Admin issued regional admin onboarding |
| `COMPLAINT_SUBMITTED` | *ARAM Complaint Registered — {ID}* | `userName`, `complaintCustomId`, `district`, `state` | Citizen complaint filing confirmation |
| `GUIDE_ASSIGNED` | *ARAM — Legal Guide Assigned to Your Case* | `userName`, `complaintCustomId`, `guideName` | Citizen notification upon volunteer assignment |
| `GUIDE_NEW_CASE` | *ARAM — New Case Assigned \| {ID}* | `userName`, `complaintCustomId`, `category`, `district` | Guide notification (no sensitive facts in email) |
